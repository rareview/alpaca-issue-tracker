# Security Policy

## Supported versions

Security fixes are provided for the latest release of Alpaca Issue Tracker. Upgrade to the [latest release](https://github.com/rareview/alpaca-issue-tracker/releases/latest) before reporting an issue on an older version.

## Reporting a vulnerability

**Please do not report security vulnerabilities in public GitHub issues.**

Instead, report them privately through [GitHub Security Advisories](https://github.com/rareview/alpaca-issue-tracker/security/advisories/new) for this repository.

Include as much detail as you can:

- A description of the vulnerability and its impact.
- Steps to reproduce, or a proof of concept if available.
- Affected versions and configuration details.
- Any suggested remediation, if you have one.

We will acknowledge your report and work on a fix. We appreciate responsible disclosure and will coordinate disclosure timing with you when possible.

## Security updates

Fixed security issues are noted in release notes and the plugin changelog as appropriate.
