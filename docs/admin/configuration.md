# Configuration

Administrators manage site-wide Alpaca Issue Tracker settings under Project Board > Configure.

## Statuses

The Statuses tab controls board columns.

Use it to:

- Rename statuses.
- Reorder statuses.
- Manage the status order shown on the board.
- Restore default statuses when needed.

## Cards

The Cards tab controls which datapoints appear on issue cards.

Use this to decide how much information appears at a glance on the board, such as assignees, labels, priority, deadlines, or other available datapoints.

## Labels

The Labels tab manages issue labels.

Labels can have names and display colors. Label colors are stored on label term meta and normalized before use.

## Deleted Items

The Deleted Items tab helps administrators find and restore deleted issues when they are still available in trash.

Restored issues return to active board usage and restoration activity is recorded.

## Settings

The Settings tab includes site-wide controls such as:

- Contextual capture.
- Test logs.

Contextual capture controls whether reporting/capture behavior is available. Test logs are intended for debugging and should not be enabled unless needed.

## Email Templates

Email Templates is a separate admin screen under Project Board. It controls shared notification and digest email templates for the site.

Template blocks, placeholders, and storage are documented in [Email Templates](email-templates.md).

## Personal Settings

My Notifications is separate from Configure. It only affects the current user's notification preferences.
